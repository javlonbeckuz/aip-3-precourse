# Praktikum 3.0. Kit 5/5: Pilot va hisob-kitob. B shakli: pilot raqamlari

Pilot faqat agentning tezligini emas, pul va vaqtda nima oʻzgarganini koʻrsatishi kerak.

- **Agentgacha** ustuni: baseline. Ikkinchi darsdan keyin boshlanadi. Tarix bor joyda (Telegram chat eksporti, Excel, CRM) oxirgi 2-4 haftani Claude Code bilan oling. Tarixi yoʻq raqamni 5 ish kuni jonli yozing. Haftalik ustunlar bilan solishtirish uchun bir haftalik raqam yozing.
- Baseline boʻlmasa, demo kunida faqat taassurot qoladi.
- Har hafta bitta ustunni baseline bilan bir xil usulda toʻldiring.
- **Oʻzgarish**: oxirgi toʻldirilgan hafta va Agentgacha ustuni orasidagi farq.
- Raqam yetmasa, katakni boʻsh qoldiring. Toʻqimang.
- Bu jadval kompaniya papkasida `kit5-pilot/results.md` boʻladi.
