# Kompaniya papkasi

Kurs davomida har Kit natijasi shu papkaga .md fayl qilib saqlanadi. Claude Code hammasini oʻqiydi.

1. Arxivni oching va kompaniya papkasini qulay joyga koʻchiring, masalan Documents ichiga.
2. Warpʼni oching va shu papkaga oʻting: cd [papka yoʻli]/kompaniya
3. claude deb yozing va Enter bosing.
4. CLAUDE.md dagi [kvadrat qavs] joylarni toʻldiring yoki toʻldirishni Claudeʼdan soʻrang.
5. Kit 1 .md fayllaringizni kit1-interviews papkasiga koʻchiring.
