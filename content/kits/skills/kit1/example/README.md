# /kit1 namunasi: qanday takrorlash

Bu papka /kit1 ni «Baraka Office» kompaniya papkasida haqiqiy ishga tushirish natijasi.

1. `input/` ichidagi fayllarni kompaniya papkangizga xuddi shu yo‘llar bilan nusxalang (yoki o‘z fayllaringizni qo‘ying).
2. Claude Code’ni kompaniya papkasida oching.
3. `suhbat.md` dagi xabarlarni ketma-ket yozing: birinchisi buyruq, keyingilari Claude savollariga javob.
4. Natija `output/` dagi fayllarga o‘xshash bo‘lishi kerak; so‘zlar boshqacha bo‘lishi mumkin, tuzilma va hisoblar bir xil bo‘ladi.

## Fayllar

- `suhbat.md`: siz yozadigan xabarlar va Claude javoblari, to‘liq.
- `input/`: skill o‘qigan fayllar.
  - `input/CLAUDE.md`
  - `input/kit1-interviews/team-message.md`
  - `input/kit1-interviews/malika-transcript.md`
  - `input/kit1-interviews/zarina-transcript.md`
  - `input/kit1-interviews/jamshid-transcript.md`
- `output/`: skill yozgan yoki o‘zgartirgan fayllar.
  - `output/kit1-interviews/malika-form-b.md`
  - `output/kit1-interviews/zarina-form-b.md`
  - `output/kit1-interviews/jamshid-form-b.md`

Uchta suhbat alohida /kit1 sessiyasida ishlangan; oxirgi xabarlar xodim B shaklini ko‘rib chiqqandan keyingi tuzatish rejimi.
Malikaning transkriptida raqam tuzoqlari bor: «34 marta» (aslida «uch-to‘rt marta») va «1 300 000» (aslida «bir uch-to‘rt yuz ming»). input/CLAUDE.md dagi soatbay haq qatori kurs kanoniga moslangan (35 700 so‘m); /kit1 bu raqamni ishlatmaydi, natijaga ta’sir qilmaydi.
