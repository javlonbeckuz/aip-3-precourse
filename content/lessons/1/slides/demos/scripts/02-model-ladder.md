# Demo script 2: the model ladder (tiers and effort)

Slot: 1:17-1:22, slide 24.
Bold term: Model tiers and effort.
Handout: `demos/models/index.html` and its PDF `handouts/pdf/bu-hafta-ai-da.pdf` (dated sheet).

## Goal

Owners see that the cheap, balanced and strong models give visibly different quality on the same Uzbek task, and that "strongest for everything" wastes money.

## Prompt (paste exactly, in a new chat each time)

```text
20 ta o‘zbek milliy taomini sanab ber. Har biriga bitta qisqa izoh yoz.
```

## Rehearsal (two days before)

1. In claude.ai, run the prompt once on each tier available in the model picker: the cheap model (Haiku), the balanced model (Sonnet) and the strong model (Opus).
   If a tier is missing from the app picker, use the Anthropic Console Workbench or OpenRouter with a small spending limit.
2. Screenshot each full answer into `ladder-screenshots/` as `1-arzon.png`, `2-muvozanatli.png`, `3-kuchli.png`.
3. Read the cheap model's list carefully and circle any dish that does not exist or any wrong description.
   In the 2.0 class the cheap model invented "shavlama"; do not promise that it will happen again.
4. Note the time each answer took.

## In class

1. Show the three screenshots side by side (or run live if Wi-Fi is good and you have time).
2. Ask the room: "Qaysi ro‘yxatda xato bor?" Let one or two people answer.
3. Say (UZ): "Arzon model saralash uchun, kuchli model reja tuzish uchun. Har ishga eng qimmatini qo‘ymang."
4. Effort, one sentence (UZ): "Effort: model javobdan oldin qancha o‘ylashi. Ko‘proq o‘ylasa, sifat oshadi, lekin sekinroq va qimmatroq."
5. Mentors hand out the dated sheet; point at the price columns, not at every row.

## If it fails

No screenshots and no Wi-Fi: skip the demo, keep slide 24, and give the rule from the dated sheet.
