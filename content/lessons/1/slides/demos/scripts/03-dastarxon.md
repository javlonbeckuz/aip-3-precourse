# Demo script 3: the context dastarxon (context window)

Slot: 1:13-1:17, slide 23.
Bold term: Context window (plus the reference term "dumb zone").

## Goal

Owners understand that a chat has a limited "table" (dastarxon), that long chats get worse well before the table is full, and that the fix is a new chat per task.

## The analogy (UZ)

"Kontekst oynasi bu dastarxon. Siz har gapirganingizda dastarxonga yangi likopcha qo‘yiladi. Dastarxon to‘lsa, chetidagi narsa tushib ketadi. Uzun chat sekin-asta xiralashadi, dastarxon to‘lishidan ancha oldin."

## Live demo (3 minutes, prepared in rehearsal)

1. In rehearsal, open one long chat in claude.ai and give it one simple rule you can check by eye.
   First message: "Bu suhbat davomida har bir javobni «Hurmatli mijoz,» deb boshla."
2. Then paste 6-8 long documents (the Baraka Office files are fine) and ask unrelated questions about each.
3. Check whether the later answers still start with «Hurmatli mijoz,».
   If the rule drops out, screenshot that answer next to the first one; that is your slide-23 evidence.
   If the rule holds, say so honestly and use the flipchart drawing (see "If it fails").
4. In class, show the two screenshots (or the long chat) and then open a fresh chat to show the clean start.

## Where to see how full the table is

- If claude.ai shows a long-chat warning or a context indicator in your rehearsal, show it; do not promise one in advance.
- In Claude Code (Day 2) `/context` shows the meter and `/compact` summarises the chat; mention it only as "next week".

## Rule to leave on the table

"Yangi vazifa: yangi chat."
Do not give a percentage for when quality drops: 2.0 said 40% in one place and 60% in another, and the real point depends on the model and the task.

## If it fails

No screenshots: draw the dastarxon on the flipchart: plates added from the left, the oldest plates falling off the right edge.
