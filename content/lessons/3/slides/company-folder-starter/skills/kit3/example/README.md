# /kit3 namunasi: qanday takrorlash

Bu papka /kit3 ni «Baraka Office» kompaniya papkasida haqiqiy ishga tushirish natijasi.

1. `input/` ichidagi fayllarni kompaniya papkangizga xuddi shu yo‘llar bilan nusxalang (yoki o‘z fayllaringizni qo‘ying).
2. Claude Code’ni kompaniya papkasida oching.
3. `suhbat.md` dagi xabarlarni ketma-ket yozing: birinchisi buyruq, keyingilari Claude savollariga javob.
4. Natija `output/` dagi fayllarga o‘xshash bo‘lishi kerak; so‘zlar boshqacha bo‘lishi mumkin, tuzilma va hisoblar bir xil bo‘ladi.

## Fayllar

- `suhbat.md`: siz yozadigan xabarlar va Claude javoblari, to‘liq.
- `input/`: skill o‘qigan fayllar.
  - `input/CLAUDE.md`
  - `input/kit2-scoring/form-b-matrix.md`
  - `input/kit2-scoring/form-a-scoring.md`
  - `input/data/narxlar.csv`
  - `input/data/qoidalar.md`
  - `input/data/ombor-1c.csv`
- `output/`: skill yozgan yoki o‘zgartirgan fayllar.
  - `output/kit3-agent/form-a-steps.md`
  - `output/kit3-agent/form-b-agent.md`
  - `output/kit3-agent/instructions.md`

Ikkinchi sessiya istisnolar rejimi: To‘plam 4 da topilgan ikki holat (tannarx so‘ralishi, ombordagi farq) xodimlar aytgan istisno sifatida qo‘shildi. instructions.md ning yakuniy holati To‘plam 5 dagi tuzatishlardan keyin `namunalar/baraka-office/kit3-agent/instructions.md` da. input/CLAUDE.md dagi soatbay haq qatori kurs kanoniga moslangan (35 700 so‘m); /kit3 bu raqamni ishlatmaydi, natijaga ta’sir qilmaydi.
